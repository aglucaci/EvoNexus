# Development Efficiency

- Inspect only task-relevant files.
- Use targeted repository searches.
- Make the smallest correct change.
- Reuse existing components and dependencies.
- Avoid unrelated refactoring.
- Do not inspect generated datasets or caches
  unless required.
- Run targeted tests first.
- Avoid repeated builds.
- Avoid redundant command execution.
- Do not install unnecessary dependencies.
- Obtain approval before expensive external
  API calls.
- Complete only the requested scope.
- Plan substantial architectural changes
  before implementing them.
- Keep responses concise.
- Stop when acceptance criteria are satisfied.
